# 자동화설비기능사 기계요소설계작업 — 공개도면 참고도면

자동화설비기능사 실기 **시험1 기계요소설계작업** 공개문제 1~20번 과제의 참고도면 학습 페이지입니다.

## 구성
- `index.html` — 과제 목록 (검색)
- `task01.html` ~ `task20.html` — 과제별 참고도면
  - A3 2D 도면 (KS 제도, 제3각법, 단면·해칭), 등각투상도 1:1 (자리가 없으면 1:2)
  - three.js 3D 모델 (정면/평면/우측면/등각 방향 보기, 흑백·CAD 색상)
  - **단면 A-A 보기 + 단면 위치 슬라이더**: 절단면을 부품 전체에 걸쳐 이동
  - **치수 가리기 모드**: 치수 문자를 가리고 칸을 눌러 하나씩 확인 (확인 개수 표시)
- `trainer.html` — 투상 트레이너 (3D ↔ 투상도 맞히기)

## 사용
각 HTML은 단일 파일이며 브라우저에서 바로 열 수 있습니다. GitHub Pages로 공개하면 `index.html`이 시작 화면입니다.
(3D는 CDN의 three.js r128을 불러오므로 인터넷 연결이 필요합니다.)
